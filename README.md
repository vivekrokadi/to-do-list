# ToDo-List

This is a simple ToDo List web application that allows users to add, check off, and delete tasks.

## Features

* **Add Task:** Users can add tasks to the list by typing in the input field and clicking the "Add Task" button.
* **Check Task:** Users can mark tasks as complete by clicking on the task's icon. The icon will change to indicate completion.
* **Delete Task:** Users can remove tasks from the list by clicking the "Delete" button next to the task.

## Technologies Used

* HTML
* CSS
* JavaScript
